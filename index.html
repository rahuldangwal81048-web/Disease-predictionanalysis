What this project demonstrates

Disease Prediction System is a front-end-only demo of how a symptom-based screening tool can work. It's built for a college minor project to show the full flow — data modelling, a scoring algorithm, UI/UX, and persistent client-side storage — without needing any backend infrastructure.

No backend required

Every file runs directly in the browser. Just open index.html — no server, PHP, Node or database setup needed.

Pluggable prediction model

The scoring logic lives in one place and can be swapped for a real trained model later without touching the UI.

Private by design

Your selections and history stay in your browser's localStorage and are never sent anywhere.

!

Educational tool only — not a medical diagnosis. Predictions come from a small demonstration dataset and a simple scoring algorithm. They are not a substitute for professional medical advice. Always consult a qualified doctor for real health concerns.
